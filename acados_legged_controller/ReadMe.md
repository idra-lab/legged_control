# INSTRUCTIONS FOR GENERATING acados SOLVER and MODEL

The *c_generated_code* folder is generated by */scripts/model_gen.py* that takes the values for the definition of the OCP and the model in *config/config.yaml* and generates the code. 

Since it uses the acados python interface for generateing the code, each time one wants to change something in the model, some weight of the OCP or other stuff related to the model, he has to regenerate the *c_generated_code* and recompile the package. 

In order to do keep the environment clean I created an *acados virtual environment* and when I need to run the *model_gen.py* I need to specify the library of acados and the virtual environment. 

```
cd ~/colcon_ws/src/legged_control/acados_legged_controller/scripts

LD_LIBRARY_PATH=$HOME/acados/lib PYTHONPATH= ~/opti_pessi_acados/acados_env/bin/python model_gen.py

cd ~/colcon_ws

colcon build --symlink-install --packages-select acados_legged_controller --cmake-args -DCMAKE_BUILD_TYPE=RelWithDebInfo
```
